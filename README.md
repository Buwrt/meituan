# 暹罗外卖用户端 App（uni-app 版）

由开源项目 [siam-cloud](https://github.com/siam1026/siam-cloud) 中的微信小程序
`wxapplet-siam-user` 通过 `miniprogram-to-uniapp` 转换而来，用于编译 Android APK。

## 使用

1. 安装 [HBuilderX](https://www.dcloud.io/hbuilderx.html)，导入本目录
2. 修改 `utils/global-config.js` 的 `baseUrl` 为你的后端地址
3. `发行 → 原生App-云打包` 即可得到 APK

详情见 `打包前请先读我.md`。
