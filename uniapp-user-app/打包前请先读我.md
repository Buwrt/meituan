# 暹罗外卖（siam-cloud）代码分析 & APK 打包指南

## 一、先说结论

1. **这个仓库里没有能直接编译成 APK 的代码**。`wxapplet-siam-user` 是**原生微信小程序**（app.js / app.json / .wxml / .wxss），不是 uni-app 工程，Android SDK 无法直接打包它。
2. 我已经帮你把它**完整转换成了 uni-app 工程**（`siam-user-app.zip`，49 个页面、组件、静态资源全部转换完成），这就是能打出 APK 的形态。
3. APK 二进制需要 Android 构建工具链（Android SDK / 构建环境 / 签名），当前环境不具备，所以**这里交付的是可直接打包的工程 + 一步步的操作指引**；你在本地 HBuilderX 里点一次「云打包」即可拿到 APK，无需装 Android Studio。

## 二、代码分析

### 2.1 项目定位

对标美团/饿了么的**多商户外卖配送系统**，含用户端（小程序）、商家端（小程序 + Web 后台）、配送端（小程序 + Web）、总管理后台。Apache-2.0 协议，v1.1，438 次提交，343 Star / 70 Fork。

### 2.2 技术栈

| 层 | 技术 |
|---|---|
| 移动端 | 原生微信小程序（用户端）；商家端/骑手端小程序**未开源**，需加群获取 |
| Web 端 | Vue + Element UI（vue-siam-shop 商家后台、vue-siam-admin 调度后台） |
| 服务端 | Spring Boot 2.3.3 + Spring Cloud & Alibaba（Eureka 注册中心 + Zuul 网关），JDK 8 |
| 中间件 | MySQL、Redis、RocketMQ、WebSocket、ElasticSearch、ELK、Sentinel、Seata |
| 运维 | SkyWalking、SpringBoot Admin、Prometheus + Grafana |

### 2.3 代码规模（实测统计）

- Java 文件 **946 个**，约 **15.9 万行**
- **129** 个 Controller、**86** 个 Service、**72** 个 Mapper、**144** 个实体
- 数据库脚本 2 个（siam_cloud.sql、siam_cloud_mall.sql），**73 张表**

### 2.4 用户端小程序结构

- **51 个页面**：首页/点餐（menu）、购物车、订单（下单→支付→评价→退款）、地址管理（7 个页面）、我的（会员、余额、积分、优惠券、邀请返现、提现、安全中心）、积分商城（internal/mall）、登录授权。
- 4 个 tabBar：外卖、商城、购物车、我的。
- UI：WeUI 组件库（dialog / half-screen-dialog / searchbar / vtabs / slideview 等 15+ 自封装组件）+ 自定义 tabbar 图标。
- 网络层 `utils/http.js`：统一 POST + JSON，Header 带 `Authorization` token，统一处理 401/403/404/500 错误码。
- 地图：`utils/gaode-libs/amap-wx.js`（高德小程序 SDK）+ 微信插件 `chooseLocation`（腾讯位置服务，appid wx63ffb7b7894e99ae）。
- 后端地址写死在 `utils/global-config.js`：`https://test-api.siam.shop`（官方测试服，**大概率已停用，必须改成你自己的后端**）。

### 2.5 架构特点与评价

- 标准的 Eureka + Zuul 单体式微服务拆分，模块边界清晰（用户/商家/骑手/商品/订单/促销/商城），适合学习微服务与外卖业务建模。
- 业务覆盖完整：多商户入驻审核、库存出入库盘点、骑手抢单、积分商城、邀请返现、小票打印、Excel 导出，功能密度在同类开源项目里属于上游。
- 需要注意：Spring Cloud Netflix（Eureka/Zuul）+ Spring Boot 2.3.3 属**较老技术栈**；商家端/骑手端小程序未开源，二次商用需自行补齐；测试接口地址与演示账号（siam/123456、admin/123456）上线前必须更换。

## 三、用交付的 uni-app 工程打出 APK

### 方案 A：HBuilderX 云打包（推荐，零 Android 环境）

1. 下载 [HBuilderX](https://www.dcloud.io/hbuilderx.html)（App 开发版），Windows/Mac 均可。
2. 菜单 `文件 → 导入 → 从本地目录导入`，选择解压后的 `siam-user-app` 目录。
3. 改后端地址：`utils/global-config.js` → `baseUrl` 改成你的服务器（如 `http://192.168.1.10:8080`），**Android 9+ 默认禁用 http 明文**，要么上 HTTPS，要么在 manifest 里开 `cleartextTrafficPermitted`。
4. 双击 `manifest.json`：
   - 基础配置：应用名称、版本号、AppID（点"获取"登录 DCloud 自动分配）、图标、启动图；
   - App 模块配置：我已勾选定位/地图/支付/OAuth/推送/分享，用不到的可取消以减小体积；
   - App SDK 配置：用到微信登录/支付/分享时填**微信开放平台**（不是小程序）的 AppID/AppSecret，用到地图时填高德 Key。
5. 菜单 `发行 → 原生App-云打包（App 云端打包）`：
   - 选 Android（apk）、支持 CPU 类型（armeabi-v7a + arm64-v8a）；
   - 证书：先用"公共测试证书"跑通，正式发布用自有证书：

     ```bash
     keytool -genkey -alias siam -keyalg RSA -keysize 2048 -validity 36500 -keystore siam.keystore
     ```

   - 勾选"打正式包"（不勾则为调试包，需配合 HBuilder 基座运行）。
6. 云端排队几分钟后下载 APK，装到手机即可。

### 方案 B：离线打包（Android Studio）

适合需要深度定制原生能力：用 `npm run build:app-plus` 或 HBuilderX「发行→本地打包→生成本地打包 App 资源」得到 `www` 资源，再按 DCloud [离线打包文档](https://nativesupport.dcloud.net.cn/AppDocs/)，把资源放进 Android 离线 SDK 工程，配置 AppKey、build.gradle、签名后 Gradle 编译。

### 方案 C：不改代码，用小程序容器

若不想改造小程序代码，可用 FinClip / mPaaS / uni 小程序容器 SDK 做一个 Android 壳，直接把原 `wxapplet-siam-user` 小程序包塞进去运行。缺点是需引入第三方 SDK、部分微信原生能力仍不可用。

## 四、转换后必须人工适配的 7 个点

转换工具（`miniprogram-to-uniapp`）完成了 88 组文件、49 个页面的 Vue 化，但**微信小程序专有能力在 App 端不成立**，需按清单改造：

1. **登录**：`wx.getUserProfile` / `wx.login` 在 App 端无效。最省事的做法是用已有的账号密码接口 `POST /api/member/login`（后端 `MemberController.login` 已支持）；要微信一键登录则改用 `uni.login({provider:'weixin'})` + 微信开放平台，后端需新增 App 登录接口（现只有小程序登录 `WxLoginController`）。
2. **支付**：`wx.requestPayment` → `uni.requestPayment({provider:'wxpay'})`，后端需接入**微信 APP 支付**（现在只有小程序支付）。
3. **选点插件**：`chooseLocation`（腾讯位置服务插件）App 端不可用。已启用 Maps 模块，需改用高德/腾讯地图原生选点，并替换 `utils/gaode-libs/amap-wx.js`（小程序版高德 SDK，App 端不可用）。
4. **订阅消息**：小程序订阅消息 → 改用 UniPush/个推（manifest 已开 Push 模块）。
5. **NFC**：`wx.getNFCAdapter` 在 App 端不支持，相关页面需删除或改为原生插件。
6. **权限**：Android 需动态申请定位、相机、存储权限；`wx.getSetting` 逻辑要换成 `uni.authorize` / `plus.android.requestPermissions`。
7. **图片上传**：`wx.chooseImage/uploadFile` 已自动转为 `uni.*`，但上传地址、Android 文件权限需真机验证；`pages/assets/logo/logo.jpg` 等个别资源路径在转换时报"文件不存在"，需核对 `static/` 目录。

**验证顺序建议**：先用账号密码登录 + 只跑首页/点餐/下单，跑通后再接微信登录与支付。

## 五、后端配套

APK 只是客户端，数据来自后端。跑通路径：

- 按 `doc/` 下的搭建文档（Windows / Linux / Docker）起 MySQL + Redis + Eureka + Zuul + 各业务服务，导入 `sql/mysql/siam_cloud.sql` 与 `siam_cloud_mall.sql`（73 张表）；
- 或先指向官方演示环境 `https://test-api.siam.shop` 验证（若仍可用）；
- 演示账号：小程序端 `siam / 123456`，商家后台 `admin-ludian / 123456`，调度后台 `admin / 123456`。

## 六、风险提示

- 自动转换 ≠ 100% 可用，49 个页面需真机逐屏验证，样式与生命周期差异（如 `onLoad` 取值、组件通信）可能需微调；`transform.log` 里记录了全部提示与告警。
- 商家端、骑手端小程序源码未开源，**本次只能产出用户端 App**；需要这两端需自行开发或向作者获取。
- 商用前务必替换默认账号密码、测试接口地址、微信/地图/支付的密钥配置。
